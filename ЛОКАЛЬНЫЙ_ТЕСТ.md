# «Мои дела» — полноценный тест в Telegram без облака

Эта версия запускает настоящее взаимодействие с Telegram прямо с вашего
компьютера. **Не нужно устанавливать функцию в Yandex, подключать Cloudflare,
создавать триггер, базу или VPS.** Используется сохранённая SQLite-база и
уже существующая логика бота.

## Как запустить на Windows

1. Скачайте GitHub-репозиторий через **Code → Download ZIP**, распакуйте папку.
2. Установите [Python 3.11+](https://www.python.org/downloads/windows/)
   (при установке отметьте **Add Python to PATH**).
3. Дважды щёлкните файл **ЗАПУСТИТЬ_БОТА.bat**.
4. Вставьте токен действующего Telegram-бота из BotFather в открывшееся
   окно, нажмите Enter, затем подтвердите запуск клавишей «д» + Enter.
   **Не пересылайте токен в чат или GitHub.** При вводе токен не отображается.
5. Откройте чат «Мои дела» в Telegram, отправьте **/start**.
6. Проверяйте: работу/личное → название → срок → напоминания
   (одно или несколько) → приоритет → карточка → изменение →
   выполнение → Excel с листами «Работа» и «Личное».

На первом запуске бот закрепляется за первым Telegram-аккаунтом, отправившим
/start. Следующие аккаунты не могут получать ваши задачи через бота.
Его данные сохраняются в файле **%USERPROFILE%\.moi-dela\tasks.sqlite3**.
Создайте приватную резервную копию, если сохраните реальные задачи.

**Для работы напоминаний окно запуска должно оставаться открытым, а компьютер —
включённым и подключённым к интернету.** Локальная версия не заменяет
постоянный сервер. После проверки перенесём ту же бизнес-логику на облако.

## Важно про старый Яндекс

Telegram не позволяет одновременно иметь webhook и getUpdates. Поэтому
при подтверждении запуска локальная версия **отключает старый webhook**
(который сейчас настроен на Яндекс). Облачная версия не будет получать
новые сообщения, пока вы не установите webhook повторно. Удалять саму
функцию, базу YDB или Cloudflare не нужно. Старые задачи из YDB автоматически
не переносятся в SQLite; это отдельная пустая тестовая база.

Токен вводится при каждом новом запуске и хранится только в памяти программы.
Никаких токенов в публичном GitHub, конфигурационных файлах или логах.

## Тестирование кода без аккаунта

python -m pip install -r local_requirements.txt pytest
python -m pytest -q

Тесты используют имитацию Telegram для проверки логики; **реальное получение
сообщений и доставку уведомлений необходимо проверить вручную в Telegram**.
